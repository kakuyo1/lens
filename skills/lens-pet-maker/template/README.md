# 模板：图片源宠物（以 Cartman 为例）

`cartman_recipe.py` 是一次完整创建的参照实现：从一张官方透明底立绘出发，做出一只
全功能（14 角色一角色一动作 + hover/movement/behavior、无配饰）的图片源宠物。
新角色从这份配方抄起，改 `id`/`name`/`SRC` 与各处数值，不要从零写。

用法：

```sh
PET_REF_IMAGE=<官方透明底 PNG> python -I cartman_recipe.py <输出目录>
```

运行后按 SKILL.md 的流程过 validate 与两道 gate。本文记录这次创建踩过的坑与
沉淀出的经验法则——新角色开工前先通读一遍。

## 经验法则

- **参考图先行**。已存在的角色：搜索官方图、下载、亲眼逐张看过，列出标志特征
  （剪影、配色、五官、比例）交用户确认后才动笔。官方图选透明底立绘，一张就够。
- **从本配方抄结构，只改数值**。姿势、表情、特效全是数据；对齐、锚点、sheet
  尺寸由 pet_kit 推导，手写坐标是所有事故的根源。
- **画布 88 + scale 2 + fit 0.8**。滑条下限 = 画布像素（×1 实际倍率），128 画布
  的包最小也要 128px——想与其他宠物同尺寸体系就留在 88；fit 0.8 让角色占比与
  随包宠物一致。
- **拟合并量化是平滑感的来源**：LANCZOS 缩到画布 + FASTOCTREE 96 色。88px 下
  显示倍率别超过 2，×3 的最近邻就是像素化的观感来源。
- **瞳孔放表情层，不在位图里**。眼神跟随只位移表情层 ±1px；位图里的瞳孔擦掉
  （用该列上方眼白的颜色填充），表情层的 2×2 小豆点才会随视线动。
- **闭眼 = 眼区还原成肤色**。表现形式先给用户挑：肤色盖住（无任何线）或加一条
  深肤色软弧眼缝。黑直线被否决过两次。
- **特效按角色气质选**：`cash`（钱）/`snack`（零食袋）/`book`（书）这类具象
  特效比通用的 hearts/stars 更有角色感；特效时长要贯穿动作
  （celebrate 16 帧、encourage 12 帧），4 帧的动作特效就是一瞬间的事。
- **动作差异靠三件套**：位移姿势 + 表情格 + 特效。单张位图无法关节化，不要
  尝试摆手臂。

## 坑（每一条都真实翻过车）

- **表情格必须只携带眼皮**。从 fitted 图派生的闭眼格若不把眼区之外全部透明化，
  会叠出一只偏移的完整影子 Cartman——分身、两个嘴、脖子上的怪东西、横竖线
  全是它的不同侧面。`lids()` 末尾的全图清零不可省。
- **mask 盒要跟着内容走**。盒顶扩到帽檐 = 青色闪现；盒底带到下巴/衣领 = 脖子上
  的嘴和莫名的肌肉纹。开嘴椭圆画在眼区下方的透明区，不要为此扩大 mask。
- **压扁（sx/sy）在图片源模式下是禁手**：它只缩身体位图，表情层的瞳孔/眼睑不
  跟着缩，蹲下时瞳孔浮出眼白。kit 会告警并忽略；姿势只用 dx/dy。
- **张开嘴的椭圆必须完整罩住位图原嘴线**（四周各留 1px 余量），否则原嘴的边角
  从椭圆外露出来 = 两张嘴。先用 ASCII 图逐像素定位嘴线的精确 bbox，再放椭圆；
  靠目测估两次错两次。
- **特效曾只存在于第 0 帧**：特效曾画在整张表坐标系上，其余帧全空。kit 已改为
  逐格绘制——若自己写渲染路径，逐帧验证效果表每格的非透明像素数。
- **量化会稀释细节**：瞳孔、嘴线的测量要在**未量化的孪生图**上做（同几何、
  `colors=None`），量化图上它们淡得测不到。
- **帽檐比眼睛宽**：闭眼补丁的上缘处理必须逐列找帽檐底边（波浪形保留），整行
  跳过帽檐行的做法会留下眼白顶弧 + 硬边界。
- **圆角矩形优于椭圆**：小尺寸下 PIL 椭圆是十字/菱形，圆角矩形近底部仍保持
  全宽，能罩住嘴线的最底行。
- **加载时机**：应用只在启动时和打开设置扩展分类时扫描包目录；改完包要托盘完全
  退出再启动，重选同一只不会重读。离屏逐帧验证走
  `tst_pet_scene.qml` 的 `test_captureImageSourcePetActions`（把包拷进
  `%TEMP%/lens-qtest-no-installed-pets/`），不依赖重启。
