# 关节动作与换装

**何时用**：读者要求 “身体和四肢真的动”，或某个角色要换造型演一段（制服版、健身装版）。
产物仍是普通动作：一张 `sprites/body/<动作>.png`（`frames × canvas`）+ 每帧锚点，格式不变。

## 配方结构

从 `template/articulated_recipe.py` 抄起：`PET_REF_IMAGE=<官方 PNG> python -I articulated_recipe.py <out>`
直接产出动作 sheet、anchors 与洋红底对照图。改 `SPEC`（fit / 嘴 / 头 / 手套 / 部件）与 `ACTIONS`（关键帧）即可。

- 画布 88、scale 2；`fit` 与原立绘的待机动作一致（同一张图必须同 fit）。
- 合成在 **4 倍超采样**上做（88 × 4 = 352）：逐帧摆部件 → 整图旋转 → LANCZOS 缩到 88 → 96 色量化。
  旋转用 BICUBIC，支点写在超采样坐标里。
- **帧保持基准位**：动作内的整体位移写进 anchors（head/face/body 同步），不烘进图里。
- 部件只有三类：头部（整块）、手套（按颜色抠）、前臂（多边形）。其余是 root。
- `pet_kit.bitmap_frame` 只做平移，关节动作**绕开它**：进程内替换 `bitmap_frame`，按帧喂已合成的图；
  或直接自己拼 sheet 再并进包。

## 头部

- **不要用手写多边形切头**。多边形必然和真实轮廓有偏差，转头就在两颊扫出月牙形裂口。
- 真实轮廓：在头部包围盒里按 “非衣身色” 取连通块（示例判据 `r − g > 90` 判为制服红/背心粉，
  按角色调），从脸上一点 floodfill 拿整块头（脸 + 帽子 + 头发）。
- 再把这整块**往衣身里扩 8 源像素**并与 alpha 相交：接缝落在同色衣身内部，转头时看不见；
  头顶与脸颊外侧仍严格贴原始轮廓，露出的是真背景。
- 支点在颈根。实际动作 ±3~5°；**±8° 仍无裂口才可交付**。

## 四肢

- 平面立绘**没有**肢体下面的像素。部件一动，原位就是透明洞——这是 “垫底” 问题，不是对齐问题。
- 垫底形状用**部件自己的剪影**（加 2 源像素羽化）。用缩小的椭圆必然漏掉外圈，读者看到的就是空白。
- 垫底层按 “身体其余部分向外膨胀几像素” 裁切，补丁不会在身后鼓出一大块。
- 位移压到 **±2~4 画布像素**，幅度靠**绕自身中心旋转** ±16~24° 表达。大位移必然撕开轮廓。
- 垫底层放在 root 之上、部件之下；待在位时被部件完全盖住。

## 嘴

- **先量原嘴笔画的包围盒**。官方立绘的嘴常比下巴线高 30 源像素，按 “脸的下三分之一” 猜就会画出两张嘴。
- 用圆角矩形把原位擦成肤色，再在原嘴**中心**画新嘴；擦除框完整盖住原笔画，下巴轮廓线留在框外。
- 尺寸按**画布像素**写，再乘 `1 / scale_x` 换成源像素——同一组数字在不同缩放的立绘上才读起来一样大。
  参考值：open `rx 3.8 / ry 1.35`，chew `2.6 / 0.85`，shout `4.7 / 1.75`，grin 半宽 `4.0` / 高 `1.05`。

## 验收

- **洋红底拼图**：每帧铺在 `#FF00FF` 上按 6~12 倍放大看。衣身内部的任何透明洞都刺眼，灰底会骗过眼睛。
- **嘴改完单独放大 8~12 倍看原嘴位置**：残留任何一笔就是 “两张嘴”，2 倍屏上能藏住。
- **极端角度探针**：头 ±8°、四肢最大摆角各渲一张，看接缝。
- 静止帧的墨迹包围盒必须等于已装待机帧（同一张图、同一 fit）。
- 换装动作的眼睛在位图里：`expressions` 指向**空白表情格**，否则表情层瞳孔会和位图瞳孔叠成双层。
  相邻动作的起止帧一律用零姿势，进出动作才不跳。

## 并进已装包

- 新增的一次性动作会按格式**自动进待机池**。只想升级某个触发就**替换该角色已有的动作**（如 `celebrate`、
  `stretch`），不要新增同名动作，否则旧动作变成额外的待机小动作。
- 只写变更的文件（动作 sheet、`animations.json`、`anchors.json`）；写前核对线上包哈希，先整包备份，
  失败按记录逐项回滚。装完重跑 `validate_package.py` 与离屏用例（命令见 SKILL.md 阶段 3 第 4 步）。
- 被替换动作的旧 `sprites/effects/<动作>.png` 要一并删掉：不引用也计入包大小。
