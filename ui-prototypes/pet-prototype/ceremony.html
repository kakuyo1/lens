    这套仪式

    1. 开启 从最近的边缘走入 → look_around 看一圈 → 站定。
    2. 换宠 旧宠走到同一边缘外 → 新宠从那里走进 → 张望一轮 → 站定。
    3. 关闭 走到边上 → 回头看看，encourage 送一颗心 → 走出屏幕。
    4. 仪式期间动开关或换宠，会立刻收尾再执行新的命令，不排队。

    没有新增美术：告辞用的爱心是现有的 encourage 效果层。多屏时以落点所在的屏为准。

    动作、帧率与锚点来自 data/pet/*/animations.json。页面只做演示，不进构建，也不代表已经实现。 —
