# 单次查词花费实测（2026-11-03）

> 权威：这是那一天的采样快照，不随源码漂移。价目以 `data/llm/pricing.json` 为准；本文件记的是测量当时的价目与结果。

## 要回答的问题

首次引导第二步的费用文案要给读者一个能理解的数字。原先的 “不到一分钱” 没有依据，本次用真实请求测一次。

## 方法

- 服务商与模型：DeepSeek，`deepseek-flash`，与开发者本机配置里的 `PROVIDER` / `MODEL` 一致。
- 请求：系统提示词按 `data/llm/request.word.json` 渲染（单义项预设，解释语言 `en`，用户消息只含一个词），`stream` 开启，取末尾分片的 `usage`。
- 两组：词源关（新读者的默认）、词源开（开发者本机设置）。每组 5 个词：serendipity、abandon、ambiguous、meticulous、reluctant。
- 花费按 `pricing.json` 的单价（每百万 token：输入 0.15、输出 0.6 美元）计算，按 `display.multiplier`（6.71）折算人民币。
- 价目表没有缓存命中价。本次每次请求都有 128 个输入 token 命中缓存（同一段固定前缀），按全价计算，所以下表是上界。

## 结果

| 设置 | 平均输入 token | 平均输出 token | 每次花费（元） | 1000 次（元） |
| --- | --- | --- | --- | --- |
| 词源关 | 333 | 80 | 约 0.00066 | 约 0.66 |
| 词源开 | 370 | 107 | 约 0.00080 | 约 0.80 |

单词条目的最大值为 0.00088 元（词源开，serendipity），最小值为 0.00063 元（词源关，reluctant）。10 次请求全部正常结束，输出均为合法 JSON。

## 结论

- 一次查词在 DeepSeek 上约 0.0007–0.0008 元。文案写 “约 0.001 元，1 元约够查 1000 次”，取上界，偏保守。
- 其他服务商未测。同样的 token 数按 `pricing.json` 粗算，`gpt-4.1-mini` 约为 DeepSeek 的 2.6 倍。文案因此点名 DeepSeek。

## 边界

- 只测了单词通道、单义项。句子、译文与实体通道的 token 更多，多义解释（`multiSense`）输出更长，都未测。
- 数字只反映 `usage` 字段的计数，没有与服务商账单逐笔核对。
- 价目与汇率随时间变化；`pricing.json` 的汇率记录 `asOf` 为 2026-10-02。
