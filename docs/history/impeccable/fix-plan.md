## 0. 排序口径

- **读者风险优先于分数**：会让读者丢卡、丢钱、走不通的，排在工艺洁癖前面。
- **高频优先于低频**：动作条每次选区都在眼前，更新卡一年出现几次；同样的工作量，先修前者。
- **先裁后做**：契约与材质类问题先写 ADR 或做一次测量，不在未裁决时动代码。D1 已回退，D2–D4 已裁，其余新问题照此办理。
- **一项一笔 commit**：每项是一个可独立回滚的候选；ADR 门的项先落 ADR，再落实现；不主动推送。
- **不为了分数做**：目标是让表面更可用，不是把 32 推到 35。

## 1. 已裁的四件事

### D1 托盘菜单保持指针优先（P1，已回退）

**决定（2026-10-25）**：曾经把托盘菜单做成可聚焦，实机首开时焦点环和首行高亮破坏了卡片原本安静的第一眼；产品方要求回退。托盘菜单改为不接管焦点，不设 Tab 站与焦点环；行与语言项保留读屏名称、角色与按压动作，指针 hover / 点击展开与选择，`Esc` 收菜单（ADR 0108 已改写）。

**代价**：键盘专用读者不能再用 Tab 操作菜单。这是为了首次观感与不改变前台窗口而接受的取舍；以后要恢复键盘路径，必须先重新裁定。

### D2 玻璃材质（边界，已裁：A 先测量）

**决定（2026-10-25）**：做一次三档测量，再决定材质。40%（现状）/ 42% / 44% 白底，真机截同一张卡，测正文与 `faint` 元信息；若最小档让正文 ≥ 4.5 且视觉差异可接受，采用它并改 ADR 0035 / ADR 0106；若没有可接受档，接受 4.39，把所有「已过 AA」的表述删掉，并把它从「待修」改成「已认」。

**落地**：

- 先读 ADR 0035 的 40% 白底约束，确认可动的是哪一层；
- 三档各截一张浅色桌面、一张暗夜桌面；正文与 `faint` 各测一次；
- 采用档要同步 `GlassSurface`、DESIGN 3.1c、ADR 0106，重拍README 的玻璃静帧；
- 不采用就只改文档，不碰材质。

**验收**：测量表写明三档的正文 / faint 比值与视觉判断；若采用，正文实测 ≥ 4.5；若不采用，所有「已过 AA」的说法为零。

**排期**：D2 的测量与 C2 并行，不占 C 编号；测量结果落 ADR 后，再决定是否改材质。
