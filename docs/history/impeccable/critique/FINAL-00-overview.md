## 3. 三个结论

### 3.1 状态诚实已经系统化，剩下的坑不再是“界面说谎”

托盘首行按 `tray_state.h` 的优先级说四态，预算耗尽压过模式名；设置的状态类 note 从 faint 升到 muted；更新卡把当前状态写成固定键值句，不让传输层原话漏到界面；年度摘要用“833 次 · 30 词”双口径（ADR 0104）；删除默认改为询问，恢复默认改成二态。这些是这一轮最实质的收益，且都落在组件或纯函数里，不是补丁。

### 3.2 无障碍从“整层空缺”降到“有地板、有明确例外”

控件层补齐了角色、名称、按压动作、Tab 站和焦点环；设置、年度网格、下拉和滑块有了完整键盘路径。无焦点浮层（气泡、动作条、通知、更新卡）保留 `WindowDoesNotAcceptFocus`，但读屏以浏览模式可达，例外写进 ADR 0107，不再被每轮评审重新判成违规。**键盘专用读者仍然进不了气泡、动作条和托盘菜单；这是写进 ADR 的代价，不是遗漏。** 托盘菜单曾试过接管焦点，首开时焦点环破坏了卡片的安静观感，已按产品方要求回退：`WindowDoesNotAcceptFocus`，行与语言项只保留读屏地板（D1 / C1，ADR 0108）。

### 3.3 结构性边界（数据可读性一项已关闭）

1. **玻璃材质**：正文提到 `text` 后实测 4.39:1，仍低于 4.5；音标、倒计时、搭配等 `faint` 元信息更低。ADR 0106 写明这是 40% 白底的材质边界，关掉它必须改材质；已裁为「先做三档测量，再决定」（D2）。
2. **无焦点表面的键盘路径**：气泡、更新卡、动作条按 ADR 0107 保持无焦点；托盘菜单按 ADR 0108 保持指针优先（C1 已回退）。它们不是同一条规则，文档要能一眼分开。
3. **动效重量**：扇面与吊牌每次选区重播约 720ms 入场，发生在读者刚读完的那行字旁；已裁并实现为首次全量、后续 `pop×2`（D3 / C6，ADR 0109），§4.17 已同步。
4. **数据可读性**：年度阈值、选中 / hover 环、统计 Known / New 下钻与筛选空态已由 C4 / C5 关闭；调色层阈值仍只在图例行末，不再是一条结构性边界。
