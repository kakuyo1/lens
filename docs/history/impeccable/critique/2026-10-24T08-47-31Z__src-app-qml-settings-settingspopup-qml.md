## 2. 设计专属性判定

**结论：是的，这套设置只可能是 Lens——但专属性的分布不均，肌肉专属、骨架中性。**

专属证据（先于评分形成，未受任何自动检测影响）：

- **悬停预览体系是招牌**：指针停在「多义解释」标题上，面板旁浮出的不是提示文字，而是读者自己的那张解释气泡（同令牌、同玻璃、按读者当前解释语言与打字速度渲染，Preview 胶囊 + 卡外 6px 虚线取景框与真气泡划清界限，UI-SPEC.md:132–139）。关着的开关强制画出「打开会得到什么」——这是把产品本体（解释气泡）搬进设置页，任何通用桌面工具抄不走。
- **克制与预览同样专属**：图片开关不设预览，因为「悬浮不是发起一次真实图片搜索的地方」（SettingsLearningPage.qml:142–143）；字体预览恒取英文那一份，因为字体只作用于英文（SettingsFontPage.qml 头注释）。对产品边界的理解长在了交互里。
- **主题体系**：「晴朗白昼/静谧暗夜/雾面玻璃/流光玻璃」命名 + 玻璃参数组（折射/描边高光）随主题条件出现——设置页继承了全产品的材质语言（13/14 号截图暗夜实测层次成立）。
- **陪伴人格渗进表单**：宠物页 40 个动作 chip（打盹/歪头/踩奶/打嗝）与「配饰名：常去午后晒窗台」的场景倾向行（SettingsExtensionsPage.qml:181–188），是养宠物的设置，不是配置桌面组件。
- **页脚没有 Save**：即时生效 + 唯一输入型设置（API key）失焦自动写——托盘常驻工具的轻量模型，注释把理由讲清（SettingsPopup.qml:256–266）。

通用化的一面：目录层与通用页的灰白卡骨架、预算页、API 配置页，拿到任何工具里都能用。专属性缺席的地方恰好是「钱与连接」——预算页一个输入框、连接页两根输入线，没有一条 Lens 的指纹。产品指纹最重的资源（预览）与最需要它的页面（预算）之间是断开的。

## 3. 整体印象

直觉：这是一块罕见地「有想法」的设置面板。多数设置页赢在不出错，这里赢在主动回答读者没问出口的问题——改之前先看到、禁用有状态行、拒绝有原因清单。380×480 的白卡上留白节奏和层级三档都立得住，暗色主题不是翻转而是重调（Dark.qml 头注释的 14/8/5.6 对比度账算得光明正大）。

但最好的能力全押在鼠标 hover 上：键盘层整层是空的，而 DESIGN.md:292 白纸黑字承诺「所有可点击元素有焦点态」。同时页脚那颗无确认的「恢复默认」和被页脚分隔线腰斩的滚动内容，说明 Operate 纪律在最后一厘米松了手。

**最大机会**：把「预览思维」从「解释会长什么样」延伸到「钱会怎么走」——预算页显示今日已花与到顶行为，让 PRODUCT.md 第 4 条原则「成本由读者掌控」从文档走进界面。

## 4. 做得好的

1. **预览体系把「识别」做到了 4 分**（UI-SPEC.md:132–152 全数落地，源码证实：SettingsLearningPage.qml:79–140 七个 SwitchRow 各带 previewKey，DropdownField.qml:191–285 的选项预览含防闪烁节拍与无内容不下卡的兜底）。02 号截图里「打字速度 3/5」这个最容易让人发懵的滑块，恰恰有演示卡兜着——最需要解释的控件配了最重的解释。
2. **渐进披露全线正确**：玻璃参数组只在玻璃主题出现（SettingsGeneralPage.qml:146,186,224），打字速度随动画开关消失（:438，注释写明「不留一个什么都不做的控件」），宠物区随主开关整体收放（SettingsExtensionsPage.qml:303–310，07 号截图关态只剩三行且禁用行文字转 faint）。条件显隐有理有据，一处不多一处不少。
3. **错误预防的暗线工程**：自定义颜色要过 AA 才允许应用、不过时按钮禁用并给出实测比值（SettingsGeneralPage.qml:375–414）；热键冲突与不含 Ctrl/Alt 的组合被拒（SettingsCapturePage.qml:131–133）；OCR 不可用三态文案对应三种原因（:145–154，04 号截图底部那行就是它）；宠物包 14 种拒绝原因全部人话化（SettingsExtensionsPage.qml:204–220）。

## 5. 优先问题

**[P1] 「恢复默认」无确认、作用域不可见，且在它什么都不改的页面上照样可点**
- 问题：页脚按钮直接 `TapHandler → restoreDefaults()`（SettingsPopup.qml 页脚），一击重置 13+ 项设置。UI-SPEC.md:157 的恢复清单不含每日预算、不含宠物开关——于是在预算页点它，什么都不变，页脚却显示「已恢复默认」。按钮文案也不说不碰 API key 与自启——这两条只活在规格和源码注释里。
- 为何伤读者：这是面板内唯一的高破坏动作，却常驻全部 11 页页脚，包括关于页与同步页。同面板里「删除云端数据」都有两步确认（SettingsSyncPage.qml:268–296），重置全部设置反而裸奔——同一块卡上两种标准。误触一次，读者的档位、主题、通道、热键、气泡时长全部回默认，而即时生效模型意味着没有撤销。
- 修法：复用面板已有的 question 通道（SettingsPopup.qml 已支持 Esc 先答题再退出），点击后行内二态确认（照抄同步页 confirmingDelete 模式，零新组件）；按钮 hover 或确认卡里一句话写明「API key 与开机自启不变」。预算页等无默认可恢复的页干脆不显示它。
- 命令：**/impeccable harden**

**[P1] 键盘与读屏层整层空缺，违反自家 DESIGN.md**
- 问题：开关、下拉、滑块、目录行、链接行、Chip、分段、图标按钮全部只挂 TapHandler/HoverHandler（Switch.qml:63、DropdownField.qml:417–441、StepSlider.qml:64、Chip.qml:57、IconButton.qml:24），无焦点环、无 Accessible 附加；五处 TextInput 未设 `activeFocusOnTab`（预算、API key 与服务地址、气泡时长、模型/字体输入），Tab 根本到不了——反而通用页的颜色输入显式设了 true。DESIGN.md:262 规定了「焦点 2px ink 外描边」、:292 要求「所有可点击元素有焦点态」，实现只落在了输入框描边上。
- 为何伤读者：键盘用户对整个设置层（除 Esc 和碰巧可达的两个文本框）零操作能力；读屏用户拿到的是一片无角色的 TapHandler 荒地。面板自己最自豪的预览体系也是 hover-only，等于给 Sam 关了两道门。这违反的是项目自己写下的规范，不是外部标准苛求。
- 修法：行级控件加 `activeFocusOnTab` + 已规定的 2px ink 焦点环；开关/下拉/Chip 补 Accessible.name 与 role；Esc 之外让 Enter/Space 驱动 TapHandler 行。键盘可达后预览可顺带挂到 focus 上，一举两得。
- 命令：**/impeccable harden**（或先 /impeccable audit 出清单）

**[P2] 滚动内容被页脚硬切，状态文案被腰斩**
- 问题：Flickable `clip: true` 到页脚分隔线为止，无渐隐遮罩。01 号截图「扩展」行的副标题「桌面宠物」被分隔线拦腰切掉；04 号截图「OCR 运行时不可用」——一条状态文案——被切一半。
- 为何伤读者：被切的不只是装饰文字，04 号那张是 OCR 的可用性状态；目录页「关于」永远折叠在滚动下方，每张滚动页的最后一行都以残缺收尾，与「安静书页边注」的气质相反——边注讲究离开时不留痕，这里内容是断着走的。
- 修法：页脚上缘加 12–16px 高、从透明到 panel 色的渐隐遮罩；或将「OCR 不可用」这类状态行改为不随滚动裁切（如并入触发通道分组卡下缘常驻）。
- 命令：**/impeccable polish**（layout 项）

**[P2] 预算页不反馈花费，钱没讲清楚**
- 问题：全页一个输入框加一句「设为 0 可暂停上限。」。`Controller.costDuty.stats.currency` 已经在这页取了货币符号，却没取「今日已花」；模型页价格行是 muted 11px 灰字，预算货币（¥）与价目货币（USD/百万 token）之间的关系全产品无处可读；「到顶后暂停取词与请求，次日恢复」（UI-SPEC.md:115 的语义）界面上一个字没有。
- 为何伤读者：预算敏感者设完 ¥5 之后最想看到的两个数——今天花了多少、还剩多少——要退出设置去托盘花费弹窗找。PRODUCT.md 第 4 条原则「成本由读者掌控」，这页是对它承诺最重、兑现最轻的一页。
- 修法：输入框下加一行「今日已花 ¥x.x / 上限 ¥y」；帮助句改为「0 = 不设上限；到顶后暂停取词与请求，次日自动恢复」；模型页价格句注明与预算货币的关系或给一句换算口径。
- 命令：**/impeccable clarify**

**[P2] 关键状态搭最弱视觉通道**
- 问题：保存反馈「已保存/已恢复默认」用 faint 11px 挤在页脚中央（11px 是全系统字号下限、faint 是最淡一档）；LinkRow 的 note 同款 faint 11px 承载的却是「未配置」「强制置顶」这类值与状态；依赖 OCR/宠物而被禁用的行只变灰不说明原因（SwitchRow.qml 头注释：「with nothing said about why」——阅读学习页「单词复习」灰着，不说是宠物关了）。
- 为何伤读者：状态与装饰同权重，读者扫一眼分不清「这里有个值」和「这里无所谓」；BYOK 产品里「未配置」是阻断全产品的状态，视觉上却和「构建于 2026-10-24」一个待遇。
- 修法：状态类 note 升 muted；「未配置」用文字强调而非新色相（One Green Rule 不破）；禁用行沿用 OCR 三态的做法补一句原因（「宠物关闭时不可用」）。
- 命令：**/impeccable clarify**

## 7. 小观察

- 「设为 0 可暂停上限」绕——语义是「不设上限」，建议直说（SettingsBudgetPage.qml）。
- 「每 1000000 个 token」应作「每百万 token」（05 号截图）。
- API 配置页帮助句「这里的地址是服务商常用的地址，可能已失效；请以服务商文档为准。」把不确定性推给读者；页内无「测试连接」、无「恢复默认地址」小动作，key 填错的发现路径绕经取词失败。
- 目录行文字左缩进 9px、页面行贴左缘 0px（SettingsCategoryRow.qml vs SettingsLinkRow.qml 注释自己记录了这个偏差）——目录进页面时左缘轻微跳动。
- 分组标签两种字号并存：取词页 11px，通用/学习页 12px——同层级同语义，两个值。
- Capture 页三处用 `qsTr`（上下文变成 SettingsCapturePage），其余全用 `qsTranslate("SettingsPopup", ...)`——翻译上下文分裂，i18n 工程债。
- 返回/关闭按钮 16px 图标、26×26 命中区；下拉展开列表独立 Window、点击外部落下、Esc 兜底，机制干净（瞬时态渲染未评估，转 qtest）。
- 关于页「检查更新」黑胶囊与同步页「使用 GitHub 登录」黑胶囊——ink/on 主操作语言全面板一致，好。
- 暗色两拍（13/14 号）明度台阶清晰、文字三档可辨，Ladder rule 兑现在像素上。

## 8. 开放问题
