# 0106 玻璃主题下正文取第一档文字色

- **状态**：accepted（2026-10-24）。五轮 critique 的修复流⑥（玻璃正文档位）随本 ADR 落地。
- **背景**：气泡的释义、义项、词源和例句原本取 `muted`（第二档文字）。实心主题上这档是 8:1，合适；
  雾面玻璃实测只有 2.33:1，弱字 `faint` 更低到 1.65:1，而正文 `text` 是 4.39:1。白底固定 40% 是
  ADR 0035 为材质定下的，实测把它抬到 64% 才能让第二档过 AA、78% 才能让弱字过 AA，等于放弃雾面。
  ADR 0035 决定的是浅字 / 深字两套，没有决定核心正文该落在哪一档。
- **决定**：
  - 色表新增语义角色 `body`：实心主题取 `muted`（保持原有的第二档层级），玻璃主题取 `text`。
  - 气泡里由 `body` 画的是读者必须读懂的答案：释义、义项英文行、词源与例句的正文及其小节标签、
    释义链当前一层的正文，以及判定 / 句子 / Preview 标签。玻璃下这些文字不再靠颜色分主次，层级由
    字号、字重和位置承担。
  - 元信息保持 `faint`：音标、倒计时、搭配、释义链面包屑、释义里可点词的点线。它们不承载答案本身，
    玻璃底图上仍可能低于 AA，这是 40% 白底的已知边界。
  - 白底 40% 不动，也不给气泡加第二层底；那会改掉玻璃的材质，而不是修文字。
- **后果**：
  - 玻璃下正文与译文同色，英文释义与其下的译文不再有一档色的差别；这是可读性换来的代价。
  - `muted` / `faint` 在玻璃上仍未达 AA（除浅色底图外）。本 ADR 只把核心正文救回到 `text`，
    没有把每个注释都拉齐；`docs/metrics/accessibility/contrast-2026-10-12.md` 的结论仍然有效。
  - `body` 是色表角色而非新颜色。其他表面若把正文画在 `muted`，可以按同一条规则改读 `body`；
    这次只改气泡，因为实测不达标的只有它的核心内容。
