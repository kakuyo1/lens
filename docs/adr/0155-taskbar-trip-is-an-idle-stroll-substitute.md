# 0155 宠物偶尔把一次闲逛换成任务栏远足

- **状态**：accepted（2026-11-06）
- **背景**：读者希望宠物在任务栏可见且不自动隐藏时，偶尔朝屏幕横向空间更大的一侧跃出，落到任务栏上，弹一下，慢悠悠走到尽头再回来，最后蹦回原处；整个过程中其它宠物内容不得插进来。宠物现有的闲逛每 2–6 分钟（按性格）才起步一次，是承接这个 “偶尔” 最自然的时机。
- **决定**：
  - **只认底部、固定的任务栏**。用当前屏的整屏矩形与工作区矩形之差求任务栏条带：只有底边有缺口、其余三边齐平才算；自动隐藏由 shell 的 `ABM_GETSTATE` 读取，勾选自动隐藏时不触发。顶部或左右任务栏没有可站立的水平台面，不触发。新增 `src/app/platform/taskbar.{h,cpp}` 放这条系统查询。
  - **概率属于性格**。`animations.json` 的 `behavior.taskbarChance`（0–1，缺省 0.3）决定一次闲逛等待到点后，是改为远足还是照常闲逛；没有任务栏、没有 `movement.walk`、起点附近放不下跃出与至少一窗宽的行走、减少动效、设置预览、拖动、仪式、抛掷、躲藏或场景入场仍在进行时，照常闲逛。包作者写 0 可关闭，旧包不写也能用。
  - **动作是纯窗口运动，不加美术**。新增 `src/app/pet/pet_taskbar.{h,cpp}`：朝横向空间更大的一侧做一个轻微抛物跃出，落到工作区底边（即任务栏上沿）。横向距离取工作区宽的 8%（至少一窗宽，受边缘空间限制），弧高 12–32 px，时长 450–1200 ms；落地立即弹起一次（14–40 px，380 ms），落稳后停 450 ms。随后向这一侧的尽头走（窗口边留约 6 px），两段都是**匀速 80 px/s**、不带步态弧线的直线，停 500 ms 后走回弹起落点；最后沿原路蹦回去：每跳升高约 44–110 px、约 480 ms，带一点上冲后落稳的过冲，同时以 60 px/s 缓慢横向回到原 x。两段行走与上升的蹦跳都使用该宠物已有的 `walk` 循环，跃出、弹起与停顿用 `idle`。这个位置与 ADR 0090 的抛掷落点一致：宠物站在任务栏上沿，不压住任务栏。起点本来就在这条线上时，跃出仍是小弧线，最后以横向小跳回到原 x。匀速与慢速是为了让整场表演不打扰读者，而不是一段需要盯着看的动画。
  - **远足期间由它独占宠物**。控制器冻结状态机时钟，待机回合、场景、打盹、学习事件的反应都不能插进来；悬浮关闭，复习提问不可用，闲逛不运行。拖动或单击是读者的干预：行程立即停在当前位置，交回给拖动或单击反应。关闭宠物、改大小、开设置预览、点场景药丸、换屏、减少动效也会结束行程；这些情形把窗口交给已有的 fit / keepOnScreen 规则，减少动效则直接回到起点。结束或取消都会重新抽一次闲逛等待。
  - **不新增设置项**。没有开关、提示或状态文字；是否发生只取决于任务栏状态、性格概率与宠物自身的走路动作。
- **后果**：新增 10 条离线的任务栏几何用例（条带识别、空间、跃出方向与弧线、弹起、匀速去程回程、蹦跳上升、全程不出工作区、起点就在任务栏上、停止）。`behavior` 块只增一个可选字段，旧包照常装载。真机上下坠与回升的距离取决于宠物当时的位置；默认落在工作区右下角时，跃出与上升只剩小弧线和横向小跳。
- **ADR 关系**：0076 的闲逛与躲藏、0090 的 “落在任务栏上沿而不是压住它”、0094 的 behavior 块、0139 的 module + adapter 结构在这里延续；排除的方案是给远足单开一套计时器（会与闲逛节奏打架）、把宠物画进任务栏条带（压住任务栏图标），以及为坠落新增动作美术（七只宠物都要重画）。
