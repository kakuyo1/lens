# 0088 提问牌立在宠物脚边，不再由手举

- **状态**：accepted（2026-10-23）。取代 ADR 0052；ADR 0053 里的小卡独立窗口与 “提问不挪宠物” 仍然有效，手的位置与抓点部分随之作废。
- **背景**：七只随包宠物共用同一张 9×8 的拳头，只有坐标不同；手有一半以上压在身体里，杆插在脸颊上，猫的右手还被画布右缘裁掉。杆画在宠物窗口上面，手指永远包不住它。继续画手要维护手部像素、左右两张 effect sheet、抓点测量、换手和躲藏时的窗口内让，成本高，而且 “一只手飘在旁边” 本身就不自然。
- **决定**：
  - 提问牌改成一块像素木牌：浅橡木板、深色边框、四枚钉子与两道木纹，一根短柱从板中央向下，柱脚踩在宠物的脚线上。木牌由牌子窗口自己画，**没有手、没有长杆、没有抓点**。木牌整块（板、柱、影子）随宠物倍率缩放，字仍为 20 px 的 Pixelify Sans。
  - 木牌的站位由宠物的**空闲墨迹盒**决定：板面在宠物身侧、离墨迹 8 px，柱脚在墨迹底边；默认左侧，木牌与小卡放不下时换右侧（`chooseSide`）。窄屏时整块水平夹进屏幕，可能压住宠物的一部分。窗口小卡与作答气泡仍按侧别让位，小卡竖直方向夹进工作区。
  - 提问期间木牌一直立着，与宠物当时演什么动作无关；宠物有这个动作时同时演 `ask`（现在只是身体起伏的展示动作），没有 `ask` 的第三方宠物也有牌子。`ask` 的左右手 effect sheet 从七个随包包里删除，装载器不再读 `effectLeft`，抓点测量与 `pet_data_test` 的握点用例一并删除。
  - 设置的动作名从 “Hold sign” 改为 “Sign”（木牌 / Cartel / 看板）；动作 id 仍是 `ask`。
  - 躲藏时提问：宠物窗口留在边缘不移动，木牌立在露出部分的内侧；原来为了让手/杆露出来而临时内移窗口的 `askShift` 删除，问题结束后 `edge_peek` 照常继续。
  - 小卡仍是独立窗口、指针在小卡或牌上即展开、120 ms 后收起；牌子与气泡 `raise()`，牌子窗口继续排除抓屏。牌子的木头是固定的宠物美术，不跟主题。
- **后果**：
  - 木牌落在宠物下半身一侧，比原来挂在头侧的纸牌低；字仍是 20 px，但小宠物的字照样会小。这是接受 “像一块立在脚边的牌子” 的代价。
  - 牌子窗口现在包含板、短柱与影子；板下柱旁是一条与板同宽、约 32 px 高的透明区。它和旧杆区同一量级，作为悬浮/点击区保留；小卡仍是独立窗口，不扩大死区。
  - 第三方包的 `ask` 效果层仍会作为动作效果被画出；格式里不再有 “左手 sheet” 的概念。随包宠物的 `ask` 效果已清空。
  - 原型已同步为木牌：`ui-prototypes/pet-review.html`、设置页的 Hold sign 预览与 `walk.html` 的躲藏提问牌卡；README 的 `review.png` 与 `learning-loop.png` 已按新原型重生成。牌子的视觉规格在 UI.md 4.13，像素木牌的实现见 `ReviewSignBoard.qml`。
  - 被排除的方案：继续用统一的手（只是位置外移）——解决了贴脸，解决不了 “七只共用一只手”；每只画自己的手——能解决独特性，但手、杆、抓点、换手与躲藏内让这套结构仍然要为每只宠物维护；纸牌加小立牌——能去手，但仍是纸牌，不是用户要的木牌。
