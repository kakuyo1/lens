# 0093 场景带时段与语境权重，待机两掷随情绪缩放

- **状态**：accepted（2026-10-24）
- **背景**：自 ADR 0049 起，场景抽签对所有场景等权，打盹与场景的概率昼夜不变。读者看到的宠物于是没有作息：深夜照样荡秋千，刚陪读者读完一段长文也不会有什么表示。产品想要的是生物钟与语境——早上更爱伸懒腰晒窗台，午后猫钻纸箱打盹，深夜猫头鹰观星、幽灵提灯；刚结束一段长阅读时更可能去敲电脑或书堆。
- **决定**：
  - **情绪是注入的纯数据**。core 新增 `PetMood`（本地时间的分钟数、是否刚结束长阅读、是否刚回到原地），由控制器从本地时钟与自己的两个 “事后语境” 戳构造，经 `MoodSource` 注入状态机；测试钉死一个 `PetMood` 即可复现任意时刻。core 不碰时钟。
  - **一天分四段**：早 5:00–11:00、午 11:00–17:00、晚 17:00–23:00、夜其余。边界固定写死，一个权重在任何机器上任何一天指同一段。
  - **场景不再等权**。`scenes.json` 的每个场景可带可选 `mood` 表（`morning` / `afternoon` / `evening` / `night` / `afterReading` / `afterReturn`），缺省 1；抽签按 “时段权重 × 语境权重” 加权，仍排除上一次的场景。权重大于 0、至多 10，坏表照旧关掉整个场景目录。
  - **用权重，不用开关**。任何场景在任何时段都保有概率，权重只倾斜，没有 “到点必演”。
  - **待机的两掷读同一个源**。场景掷与打盹掷各乘一个情绪系数：场景——晚 ×1.25、夜 ×0.5、刚读完 ×1.5、刚回来 ×0.5；打盹——早 ×0.5、午 ×2、夜 ×2、刚读完 ×0.5、刚回来 ×2。情绪缺位时系数为 1，行为与从前完全一致。
  - **两个事后语境**：一次 ≥3 分钟的阅读结束后 2 分钟内算 “刚读完”；一次闲逛收步后 90 秒内算 “刚回来”。时长是旋钮，不随本决定冻结。
- **后果**：
  - 不画新图。19 个场景全部复用，`rain` / `skate` / `swing` 不带 `mood` 表，数据本身就演示了可选项。
  - 场景目录属于应用，`mood` 表不进宠物包格式；包没有场景，权重对包无意义。基础概率来自各宠物的 `behavior` 块（ADR 0094），情绪只缩放它。
  - 情绪系数与四段边界是拍定的值，实机可调；调时改 `pet_mood.cpp` 的表，数据的含义不变。
  - 本 ADR 只改概率；三个语境的可见回应见 ADR 0098，概率规则不变。
