# 0098 情绪用三个一次性动作露出来

- **状态**：accepted（2026-10-24）。补充 ADR 0093：情绪不只乘概率，还在三个语境各给一个可见回应。
- **背景**：0093 的情绪只缩放场景与打盹概率，读者要连看许多个待机回合才可能察觉；长阅读、闲逛回家与睡醒这些本来有时序的时刻，宠物看上去和平时一样。
- **决定**：
  - 长阅读结束后的第一个待机回合改播一次 `stretch`，没有这个角色就播 `look_around`。它发生在场景、打盹与随机动作三掷之前；同一个 “刚读完” 语境只回应一次，标志回落后才允许下一次。
  - 闲逛收步、回到原地时立刻播一次 `look_around`，然后才回到待机计时。躲藏不经过收步，所以不播。
  - 自然睡醒（打盹钟到点）或读者恢复预算暂停的那次醒来，立刻播一次 `stretch`，没有就 `look_around`。被点击、拖动或学习事件打断的睡眠不补播。
  - 三个回应只用现有角色与 `playRole()`，不新增动作、美术或数据字段。`yawn` 不作为回退：它的 `returnTo` 是 `sleep`，会把宠物送回睡眠。
- **后果**：
  - 没有 `stretch` 的包用 `look_around`；`look_around` 是必需角色，所以每个包都有回应。
  - 长阅读的回应占用的是本来要掷场景与打盹的那次待机回合，之后的回合仍按 0093 的权重走；闲逛与醒来的回应不改变任何概率。
  - 每个语境只触发一次，没有自己的定时器，也不会随待机节拍重复。
