# 0067 气泡上的解释语言快捷切换会重取当前卡片

- **状态**：accepted
- **背景**：解释语言原本只在设置里改。读者读英文释义读不懂、想换中文看一眼时，要先关气泡、开设置、翻到 “阅读学习”、改语言，再回到原文重新取词；这段路正好发生在他最不想离开当前卡片的时候。反过来，如果快捷入口只换这一张卡、不改设置，下一张卡又回到读不懂的语言，读者会以为切换没生效。
- **决定**：气泡右上角、关闭按钮左侧放一枚 “地球 + 当前语言代码”。点开在卡片内展开四门语言（English / 中文 / Español / 日本語），选中即写入**全局**解释语言，并重取当前卡片（`AppController::reexplainIn` → `ExplanationDuty::reexplain`）。重取先查目标语言的缓存：有就直接换卡、不发请求；没有才重新发给模型。卡片原来的形态随选择一起走（`PendingSelection` 带上 `countsDown` / `verdictButtons`），所以复习答案卡重取后仍然没有已会 / 新词按钮。译文气泡不出现入口（答案恒为英文，与解释语言无关），词汇列表悬浮复习卡也不出现（它没有倒计时、属于指针所在的行），设置页的功能预览不画。
- **后果**：切换可能花一次请求，这是读者按下语言项时明确要求的；缓存命中时没有这笔费用。切换开始时的卡片位置和高度被保留为这一轮的下限（`Bubble.languageReplay`），布局不再按新答案的高度重排，避免同一张卡在读者眼前跳动或让玻璃底重铺；新答案只在原卡里从第一个字重新写出，译文比原文短时下方留白，直到气泡关闭或换成下一张卡。没有做 “只换这一张、不改设置” 的临时覆盖：那会让设置值和读者眼前看到的答案长期不一致。
