# 0130 本地与在线 OCR 分开选择，截图上传单独授权

- **状态**：accepted；本地 Tesseract/RapidOCR 与在线路径已实现；Windows OCR 已由 ADR 0133 移除。
- **背景**：读者希望选择随包 Tesseract 或自行安装的 RapidOCR／PaddleOCR，也希望配置在线 OCR。把它们放进同一自动回退链，会在本地失败时无声上传截图，并让自动扫描持续产生网络请求和费用。
- **决定**：手动截图分本地与在线模式，缺省本地；本地自动策略使用 Tesseract，RapidOCR 只能明确选择，不静默回退。安装包只带 Tesseract 与英文数据，可选程序和模型由读者自行安装。在线 OCR 仅用于明确确认的手动选区，不用于扫描，不成为本地失败的兜底，不自动重试或切服务商；OCR 凭据独立于解释凭据。技术契约见 `PRODUCT.md` 的 OCR 约定、`SECURITY.md` 与 `API.md` §8。
- **后果**：第一批可选本地和在线协议分别做有界 Adapter，不能把任意程序或服务当作兼容。在线模式会把选区像素交给 OCR 服务，文字脱敏不能保护此前已上传的图片；需更新产品、安全说明和上传确认。保留 Tesseract 意味着安装包仍承担其体积。此次不重写 ADR 0014 的历史。
