# 0130 本地与在线 OCR 分开选择，截图上传单独授权

- **状态**：accepted，目标决定；实现待完成，当前运行版本仍遵循 ADR 0014 的 Tesseract 路径。
- **背景**：读者希望选择 Windows OCR、随包 Tesseract 或自行安装的 RapidOCR／PaddleOCR，也希望配置在线 OCR。把它们放进同一自动回退链，会在本地失败时无声上传截图，并让自动扫描持续产生网络请求和费用。
- **决定**：手动截图分本地与在线模式，缺省本地；本地自动策略在支持条件和语言满足时优先 Windows OCR，否则 Tesseract 兜底。明确选择后端不静默回退。安装包只带 Tesseract 与英文数据，可选程序和模型由读者自行安装。在线 OCR 仅用于明确确认的手动选区，不用于扫描，不成为本地失败的兜底，不自动重试或切服务商；OCR 凭据独立于解释凭据。技术契约见[开发方案](../ocr-development.md)。
- **后果**：系统语言包与 Windows package identity 需要部署验证，不能承诺所有未打包程序都受支持；第一批可选本地和在线协议分别做有界 Adapter，不能把任意程序或服务当作兼容。在线模式会把选区像素交给 OCR 服务，文字脱敏不能保护此前已上传的图片；需更新产品、安全说明和上传确认。保留 Tesseract 意味着安装包仍承担其体积。此次不重写 ADR 0014 的历史，实际切换实现后再标记取代关系。
