# 0109 动作条形态只在首次全量入场

- **状态**：accepted（2026-10-25）。
- **背景**：扇面与吊牌的入场各约 720ms，发生在读者刚读完的那行字旁。第一次遇见一个形态时，这段展开在教读者它是怎么张开的；同一天第五十次选词时，它只是税。规格 §4.17 原来给每次出现都记同样的时长。
- **决定**：每个形态在**同一运行**里第一次出现时用全量入场；再次出现把扇面 / 吊牌的入场时长减半（`pop × 4` → `pop × 2`），幅度与曲线不变。`Tokens.motion.reduced` 下仍为 0。页边签与手牌原本是 2×pop / 2×bubble，不在这次减半里。
- **后果**：读者第一次看到某个形态时仍得到完整教学；之后的选区不再被 720ms 按住。形态切换算一次新的首次——换到没见过的形，仍用全量。实现只在 `SelectionBar.open()` 记每个形态是否已出现，并把 `entranceFactor` 交给吊牌与扇面；没有新增表面或用户设置。
