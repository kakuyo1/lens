# 0066 宠物悬浮是距离感知，不是扩大的点击区

- **状态**：accepted
- **背景**：桌面宠物原先只有点击、拖拽与业务事件会触发动作，指针靠近时没有任何反馈。宠物窗口恰好是画布大小；如果为了接收 hover 把窗口放大，或加一层透明的 `MouseArea`，会吞掉读者在宠物周围点桌面的操作，也会制造看不见的点击死区。鼠标穿透开启时更不该碰指针。
- **决定**：
  - 控制器沿用现有的 20 ms 帧时钟轮询 `QCursor::pos()`，把屏幕坐标换算成宠物画布单位，再量到**空闲帧实际墨迹的外接框**。不扩大窗口，不加命中区域，不装额外钩子。空画布的边距不算距离，所以靠近的是宠物本身，不是它所在的方形窗口。
  - 两圈，单位是画布像素：外圈 26 px 只让表情层沿主轴偏移 1 px；近圈 16 px 才进入反应。离开时加 4 px 回滞，避免边界抖动。
  - 近圈停留到该宠物自己的 `noticeDelayMs` 后播放第一个单次动作；继续停到 `dwellDelayMs` 再播放第二个。每轮最多各一次；离开至少 800 ms 才重新计一轮。刚打过招呼又回来，在 `cooldownMs` 内只安静地看着。
  - 只借空闲时间：阅读、思考、睡眠、举牌、拖动、场景和任何其他单次动作播放时，悬浮状态整体重置；点击、拖拽与学习事件永远优先。设置预览打开、鼠标穿透开启或窗口不可见时关闭。
  - 动作与节奏来自 `animations.json` 的可选 `hover` 块：`notice` / `dwell` 必须是该宠物已有的单次动作，三个延迟默认 350 / 2600 / 8000 ms，范围 0–60000 ms。没有这个块的宠物包仍然有视线跟随，只是不播靠近动作。
  - 眼神偏移只作用于表情层（`Pet.gaze`），配饰、锚点与身体不动。偏移沿指针相对墨迹中心的主轴取 ±1 画布像素；其他状态归零。（2026-10-24 修订，见 ADR 0095：躲在边缘偷看时注视跟随恢复，距离量到露出的那一小条，但反应仍不触发。）
- **后果**：
  - 悬浮依赖轮询，所以不改变任何窗口的鼠标语义；透明边距仍然不属于交互范围，鼠标穿透仍然完全关闭它。
  - 场景中不悬浮；场景里的宠物已经换了位置与缩放，按基础画布量出的距离会误导，宁可不做。
  - 长时间阅读期间即使指针停在旁边，结束后也会从新的一轮开始，不会积压出 “阅读一结束就连续演两个动作”。
  - 没有 `hover` 块的第三方包只获得眼神跟随；这是保守的默认，不要求作者升级数据。
  - 悬浮属于宠物美术行为，和减少动效设置无关（ADR 0023）；它不是界面过渡。
  - 备选方案是用更大的透明窗口加 `HoverHandler`，或直接读取指针下的像素。前者破坏桌面点击，后者没有任何必要；都没有采用。
