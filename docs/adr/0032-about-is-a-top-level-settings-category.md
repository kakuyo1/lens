# 0032 “关于” 作为设置目录末尾的一级分类

- **状态**：accepted（例外了 `ui-prototypes/README.md` 里 “不新增一级分类” 的规则）
- **背景**：检查更新原先放在通用分类，读者要找版本号和仓库地址没有入口。设置目录现有六项，首页只列分类，把关于内容塞进任一现有分类都不成立。
- **决定**：设置目录末尾新增 “关于” 一级分类，承载检查更新、GitHub 仓库、版本号与页脚（软件名、版权、构建日期）。通用分类只保留 “启动时检查更新” 开关。
- **后果**：
  - 目录由六项变为七项，首页仍一屏可见。这是唯一的例外，之后再加一级分类须另写 ADR，不能援引本条。
  - 版本号取自 CMake `project()`，经 `UpdateDuty` 已有的版本字段读出，不另建一份常量。构建日期是编译期 `__DATE__`，只在包含它的编译单元重编时更新，不是运行时间。
  - 被排除的方案：把仓库地址与版本做成通用分类的页脚。通用页会继续变长，而读者找版本的地方本来就该是 “关于”。
