# 0144 首次运行引导只弹一次，缺 key 时托盘首行常驻

- **状态**：accepted（2026-10-30）
- **背景**：Lens 纯托盘常驻、无主窗口，装完只有一个托盘图标。没有 API key 时取词与解释都不会成功，但读者看不到任何东西：启动只写一行日志（`main.cpp`），托盘 tooltip 与菜单都不提缺 key。“设置文件是否存在” 不能当首次运行的判据：启动时的更新检查就会写入设置文档。
- **决定**：设置文档新增 `ONBOARDING.done`。启动时若未记入，且没有 key，弹一张通知卡，动作 “添加 API key” 直达设置 › 模型服务，并记入；已有 key 的读者只记入、不弹。没有 key 期间，托盘菜单首行一直显示 “尚未设置 API key”（`warn`，整行可点，机制同预算耗尽行），tooltip 的模式位同步替换。编译开关 `LENS_FORCE_ONBOARDING`（CMake，默认 OFF）：开启时每次启动都弹，且不记入，供检查这张卡；关闭时按上面的规则。判定是 `core/domain/onboarding.h` 里的纯函数，由 gtest 覆盖。
- **后果**：`ONBOARDING` 不在同步白名单，每台设备各引导一次。卸载不删设置文档，重装后不再弹。菜单首行是常驻提示，不是一次性的：读者不设 key 就会一直看到它，这是有意的。被排除的方案：`QSystemTrayIcon::showMessage` 的系统气泡（不在设计系统里，要另记）；自动打开设置窗口（读者还不知道 Lens 是什么，打断过重）；以设置文件是否存在判断（见背景）。
