# 0160 铅笔层的掌握按钮：一只可输入的小窗，层保持穿透

- **状态**：accepted
- **背景**：铅笔层是点击穿透的全屏窗口（0154），层上没有任何输入，读者逐词判定只能绕道 Alt 悬停的气泡或词汇弹窗。0159 落地时先做了 Alt+M 键盘手势，读者的要求是否掉它：判定要完全不进键盘流程，单手鼠标完成。
- **决定**：
  - **按钮自成一窗**：指针在虚线词上驻留约 400 ms，词上缘正中浮出一枚 “Mastered” 胶囊小窗（无边框、置顶、不取焦、不进抓屏），点它即把该词判为掌握。层本身保持穿透——可输入的只有这一小窗，0154 的决定原样不动。
  - **悬浮靠轮询，不靠事件**：层收不到指针事件，PencilDuty 的 120 ms 定时器在页上有词期间一直轮询光标（`wordAt` 命中即计驻留）；保活矩形 = 词框 ∪ 按钮矩形——按钮窗口向 duty 上报**自身真实几何**（位置与尺寸实时回报），夹取、缩放都不产生漂移，指针离开两者按钮即收；换词、翻页、按 Alt（路标与气泡接管指针）都先收按钮。按钮立起后指针扫到相邻虚线词，按钮直接跟移过去：虚线词肩并肩，逐词重新驻留永远够不着。
  - **不进抓屏**：按钮改变抓图指纹会让虚线整层收起，所以与层一样 `excludeFromCapture`，但不设穿透。
- **后果**：
  - 页上有虚线的整个期间多一只 120 ms 的光标轮询定时器（`wordAt` 线性扫一遍页上的词，代价可忽略）。
  - 按钮遮住词上方约一粒胶囊高的页面内容；只在驻留后出现，指针离开即走。
  - 撤销掌握走词汇弹窗与气泡的新词胶囊，按钮本身不做第二态。
  - 被排除的方案：收掉层的 `WS_EX_TRANSPARENT` 让整层收输入——穿透是窗口级开关，开着时整屏点击都会被层截走，转发回页面太脆；Alt+M 键盘手势——多一根手指的动作，读者明确不要键盘参与判定。
