# 0101 场景入场是宠物的动作，不是界面转场

- **状态**：accepted（2026-10-24）。
- **背景**：场景抽到、设置页点了场景药丸，原本都是同一帧换成道具与场景姿势。读者看到的是宠物突然出现在浴缸、纸箱或秋千上，缺少 “走进去” 的因果。DESIGN.md §5 的 “不加转场” 约束的是界面卡片与表面之间的切换，不适用于宠物自己的动作；进出场仪式和抛掷已经在做同类角色运动。HTML demo 里试过现状硬切、按场景编排与通用淡入，选了按场景编排。
- **决定**：
  - 场景目录增加可选的 `entry` 块，写 `style` 与每场的差异：`hop` / `settle` / `fade`，可覆盖 `prepMs`、`moveMs`、`propMs`、`arc`、`cross`、`propRise`；`impact` 写 `kind`（`splash` 或 `dust`）与场景坐标里的 `at`。19 个随包场景全部有名有姓，新增场景可以不带（退回硬切）。
  - **hop**：道具在 180 ms 内淡入；宠物仍用 idle 身体，先站在 front 层之前，再沿抛物线移动到场景第 0 帧；弧高按宠物实测头顶余量封顶，避免高个宠物在 88 px 画布顶端被裁掉；过 `cross` 后画到 front 层之后，下半身被道具挡住；落地换成场景身体、从第 0 帧开始，水花或尘土只画在落地瞬间。泡澡、纸箱、秋千、滑板、蹦床、温泉等用这一档。
  - **settle**：道具淡入；宠物以 idle 姿势滑向场景位置并缩放，最后 180 ms 把场景第一帧交叉淡入，落地后回到 front 之后。书堆、桌面、阳光窗台、烤炉等用这一档。
  - **fade**：宠物一开始就是场景姿势，只有道具在 260 ms 内淡入；镜子、雨、云朵等没有明确 “坐进去” 的场景用这一档。
  - 控制器拥有时间轴和所有绘制值，向 QML 暴露一个 `sceneEntry` 映射（活动状态、前后层、道具透明度/位移、两层姿势的透明度、场景姿态与 `impact`）。QML 只加道具透明度与位移、宠物 rig 的 z、settle 的第二层姿势和一层像素粒子。
  - **预览不演入场**：动作药丸里的场景预览仍是静止的场景第 0 帧（`preview()` 不启动 entry）；设置页的场景药丸走真实场景 `setScene()`，会演。减少动效（Windows 或应用开关）时直接落到场景第 0 帧，不播粒子。
  - 不新增宠物或场景美术。水花与尘土是 QML 画的 1–2 画布像素矩形，坐标与颜色都在 `SceneEntryEffect.qml`。
- **后果**：
  - 场景的 30 秒从抽到场景时开始计时，入场约 0.3–0.8 秒会占用其中的开头；落地后身体与场景帧从第 0 帧重新开始，循环读起来完整。
  - hop 期间机器的语义动作仍是场景（`action()` 报场景名），但身体、锚点与配饰画的是 idle；配饰的可见性跟着屏幕上的姿势走，落地后才按场景动作过滤。
  - `entry` 走场景数据，调弧线、落点或粒子位置不需要改 QML；改渲染器时要保留 `mood`（它本来就只写在运行时目录里）。
