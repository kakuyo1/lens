# 0100 窗口落点是读者的，不是宠物的

- **状态**：accepted（2026-10-24）。
- **背景**：ADR 0096 让每只宠物记住自己的落点，换宠时新宠回到它上次待的位置。实际使用时，同一块桌面上的窗口被不同宠物搬到不同地方：读者刚把宠物安顿在屏幕一角，换一只就被搬到旧位置，再换回来又跳走，读起来是 “乱”，而不是 “每只宠物有自己的窝”。大小与配饰是宠物的身份；落点只是窗口在桌面上的位置。
- **决定**：
  - `PET.pets[<id>]` 只留 `size` 与 `accessories`；窗口落点回到 `PET.position`，一份，属于读者。
  - 换宠的落点保持窗口当前所在的位置，不跳回任何记忆；仪式仍会让窗口短暂离屏再回到同一点。新宠在屏幕边缘放不下时按工作区夹回；夹动后的位置是真实位移，写回这一份落点。
  - 一次性迁移：`PET.position` 完整时以它为准；否则把当前在场宠物 `pets[<id>].position` 上移。随后删除所有 `pets.*.position`，旧位置不留副本。
  - `PetStore::position()` 与 `setPosition()` 不再收宠物 id；开关、鼠标穿透与确认列表仍全局。
- **后果**：
  - ADR 0096 的 “换宠即回窝” 与 “第一次上场写窝” 作废；它的大小与配饰部分继续有效。
  - 切到另一块屏后再换宠，窗口留在当前屏；把宠物换屏仍需拖动。
  - 旧文档里其他宠物的落点被删除；升级后以在场宠物的位置为准，其余无从恢复。
