# 0054 退出动画先播完，窗口才收起

- **状态**：accepted
- **背景**：表面的出现一直有淡入和 8 px 上浮，退出却多是 `visible = false`，卡片被整块剪掉。给退出补上
  对称的淡出后，出现了两个新问题：窗口在淡出期间仍然存在，谁能按到它；以及调用方过去把 “窗口不可见”
  当作 “事情办完了” 的信号，而淡出把这两件事分开了。
- **决定**：外观只负责窗口何时消失。关闭通知、提交删除决定、放弃一次复习这类语义回调在点击当下发出，
  淡出只延迟 `visible`。淡出中的表面禁用内容；删除确认在可见期间始终保持 `WindowModal`——Qt 只在窗口
  显示与隐藏时登记、注销模态窗口，可见时改成 `NonModal` 会把条目留在列表里，而 `QApplication` 把这种
  残留当作应用级模态，整个应用会永久失去输入。窗口随淡出隐藏时由 Qt 一并解除模态。
  确认句里的词由 `displayWord` 缓存，调用方可以立刻清空待删除的词。
  `Bubble` 与 `SelectionBar` 自绘卡片（阴影要从纯形状副本投出，`ShadowCard` 的布局给不了），它们的
  出现与退出统一走 `SurfaceFade.qml`，而不是把 `ShadowCard` 的绑定再抄两遍。
- **后果**：调用方不能再假设 `visible` 会同步翻转，等待它变假的代码要用 `tryCompare` 一类的方式；
  测试与截图要等一个动效令牌。应用的语义状态由所有者提前清空，不能等 `visible` 的变化来清。
  外观因此有两个所有者：`ShadowCard` 管面板类表面，`SurfaceFade` 管自绘卡片；两处都保持
  “一个值驱动透明度和位移”，减少动效时一起归零。
