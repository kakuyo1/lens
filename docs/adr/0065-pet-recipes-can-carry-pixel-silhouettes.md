# 0065 宠物配方可以直接携带像素轮廓

- **状态**：accepted
- **背景**：定稿的短耳猫、小幽灵、小水母与小云不是椭圆和矩形的组合：猫耳、幽灵的波浪下摆、水母的触手、云的整团宽顶都需要逐格轮廓。原来的 `render_pet.py` 只把基础椭圆与若干椭圆/矩形合成身体，而且头锚点与姿势轴写死在椭圆的上下端。用形状近似会把定稿改形，也会让帽子、眼镜和举牌的手对不上。
- **决定**：配方增加三项可选的底层能力，仍由同一份 JSON 驱动：
  - `silhouette` 是一张 `mask` 形状，`#` 表示身体内部；它按姿势缩放，作为每一帧的底层轮廓。
  - `pivot` 与 `head` 覆盖姿势轴和头锚点，不再要求轮廓必须是椭圆。
  - `facePaint` 画在表情层，随 `face` 锚点移动，用于轮廓外的胡须；`bodyPaint` 可以写在配方级，作为所有动作的默认色。
  - `mask` 也可以作为普通的 `frame.shapes`，与 ellipse/rect 一样支持 `add` / `discard`。
- **后果**：轮廓与着色格是配方里的原始像素，配方比形状版更长；换来的是定稿像素稿可以原样进入 `data/pet`，不需要为每只宠物写死渲染器。睡眠这类压扁动作的 `bodyPaint` 由生成器按姿势重算，渲染器仍把 `bodyPaint` 当显示空间。短耳猫与三只新宠物共用九件配饰的 id，所以换宠物时配饰能保留；麻糬、猫头鹰与狗的配方不动。
