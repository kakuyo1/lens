# 0108 托盘菜单打开时接管焦点

- **状态**：accepted（2026-10-25）。
- **背景**：托盘菜单是读者主动打开的菜单，规格写着语言行是 `Tab` 站、列表展开时当前语言行接管焦点。窗口却没有 `WindowDoesNotAcceptFocus`，展示路径也不请求激活；Escape 的实现注释又假设窗口从不激活。规格、实现和激活模型三方不一致，键盘读者实际上进不了菜单。
- **决定**：
  - 托盘菜单打开时 `requestActivate()`，焦点先落在第一行（今日统计）。
  - 语言行保留 `Tab` / Enter / Space；列表展开时当前语言行接管焦点，收起时焦点回到语言行。
  - `Esc` 是两级：先折语言列表，再收菜单。
  - 其余无焦点浮层继续按 ADR 0107 不接管焦点；这条只适用于读者主动打开的托盘菜单。
- **后果**：
  - 打开托盘菜单会让 Lens 成为前台应用，读者当前窗口失去焦点。这是“菜单”与“旁注”的区别：菜单是读者主动叫出来的，气泡与动作条不是。
  - UI-SPEC 4.2 的键盘承诺有了实现依据；新增一条真平台焦点用例，离屏 qtest 只证明焦点链。
