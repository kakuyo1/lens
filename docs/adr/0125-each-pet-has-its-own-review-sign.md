# 0125 每只随包宠物有自己的复习牌，木牌留给外部包

- **状态**：accepted（2026-10-26）；部分取代 ADR 0088 中 “七只随包宠物共用一块木牌” 的那一条。木牌的站位、只放单词、整块随倍率缩放仍有效。
- **背景**：ADR 0088 让七只随包宠物共用同一块木牌，只有坐标不同。读者要的是每只宠物一块自己的牌子，外部拓展宠物则需要一个默认牌。`ui-prototypes/pet-signs.html` 为每只宠物画了三个候选（共 21 个，逐像素绘制），读者从中选定了七个。
- **决定**：
  - 七只随包宠物各用一块自己的复习牌。选定的候选：猫 纸箱蝴蝶结、奶糖 骨头牌、小幽灵 小蜡烛、小水母 小鱼缸、小云 小云朵、麻糬 纸杯蛋糕、猫头鹰 书袋卡。画法、尺寸与脚线规则以原型为准，它们是选定的设计，不是草图。
  - 原来的浅橡木木牌保留，作为**外部拓展宠物的默认牌**（原型里的 `WOOD` 候选，逐像素复刻 `ReviewSignBoard.qml`）。
  - 牌子仍只放一个单词，20 px Pixelify Sans，一行不换行。装饰（蝴蝶结、星星、爪印、圆点）不放字。
  - 站位与脚线规则不变：底边踩在宠物的脚线上，整块随宠物倍率等比缩放（ADR 0088）。
- **后果**：
  - 牌子的宽度随单词变化。原型是逐个单词重画的，装进应用需要一种随单词拉伸的办法，本 ADR 不定。
  - 每块牌的高度与脚线位置不同（例如骨头牌 40 px 高、脚线在 38；小鱼缸 72 px）。`ReviewSignLayout.qml` 目前按木牌的固定 `designHeight` 与柱高计算，要改为读每块牌自己的尺寸。
  - 装载范围（只随包宠物，还是宠物包也能提供牌子）未定。在此之前外部包一律保持默认木牌，与现状相同。
  - `UI-SPEC.md` §4.13 仍写着 “所有宠物共用一块木牌”，实现前要同步。
- **被排除的方案**：
  - 七只共用一块板、只换颜色或配饰——读者要的是每只一块不同的牌。
  - 在 QML 里为每块牌各写一段绘制代码——形状与细节都要手工维护，逐像素的质感也难以保持。
