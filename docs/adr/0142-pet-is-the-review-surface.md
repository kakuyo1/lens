# 0142 桌面宠物是复习的提问界面，不再只是附赠

- **状态**：accepted（2026-10-30）
- **背景**：产品最初只讲 read English in English，桌面宠物作为随包的附赠默认关闭，PRODUCT.md 第 62 行写 “只用来陪伴”，README 也标成 “可选”。但 ADR 0050 起宠物已经承担复习提问：到期的词在它脚边立起木牌，答完才升降等级。它是到期词回到读者眼前的唯一入口，功能量也早已超出附赠的范围，文档与功能不一致。
- **决定**：宠物定位为复习的提问界面，是产品本体的一部分，写进 PRODUCT.md 的定位段。它仍然不参与取词与解释，默认关闭，只收宠物事件、读不到屏幕内容，这几条不变。
- **后果**：“只用来陪伴” 一句撤掉，改为 “不参与取词与解释，负责复习提问”。README 的宠物标题与 “为什么是 Lens” 同步改写。被排除的方案：把宠物搬出 “扩展” 分类，这是设置页的信息架构改动，另议；让宠物参与取词，违背 read English in English。
