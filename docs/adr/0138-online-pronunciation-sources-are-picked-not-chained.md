# 0138 在线发音来源由读者显式选择，一家一个 Adapter

- **状态**：accepted；有道（缺省）与 Google 翻译已实现并接入设置。Cambridge Dictionary 暂缓：其站点对非浏览器客户端返回 403，实现它需要伪装成浏览器，本决定不做。
- **背景**：ADR 0134 只接了有道一家词典端点，它对句子与部分短语会返回 500，且读者没有其它选择。接口（`PronunciationSource`）从一开始就是为多家留的，但 `SpeechDuty` 构造时绑定了单一来源，设置里也没有来源选项，缓存键只看口音与词，两家的录音会被当成同一个文件。候选中：Cambridge 的词条页内嵌了每个词的音频地址，但站点用 Cloudflare 拦截非浏览器请求（Lens 的 UA 得 403，浏览器 UA 才得 200）；Google 翻译的语音端点（`translate.google.com/translate_tts`）无 key，单词与词组都返回 mp3，`tl=en-US` 与 `tl=en-GB` 是两份不同的录音（实测字节数不同）。
- **决定**：
  1. 在线来源由 `speechOnlineProvider` 显式选择，取值 `youdao`（缺省）与 `google`。它同时决定在线引擎与在线兜底用哪一家；不做按顺序依次尝试，也不在两家之间静默切换（同 ADR 0130 与 0134）。
  2. 每家一个 Adapter，编译期常量地址，读者不能填自定义地址。`OnlineSources` 持有全部 Adapter，`SpeechDuty` 每次发音按设置取一家。
  3. 缓存键加入来源：`sha1(来源|口音|词)`。改键后旧录音不再命中，它们可以重新获取，所以不做迁移。
  4. 本版只接受无 key 的来源。需要 key 的候选（Merriam-Webster、Forvo）不接，凭据槽与出站确认文案都不在本版范围内。
  5. Google 翻译端点是非官方接口，`client=tw-ob` 是公开网页组件使用的标识，不是我们的账号。它的条款本决定没有核实。
- **后果**：
  - 每新增一家是一个 Adapter 文件、一个 `OnlineSource` 值、一行设置选项、一个分支与 API 分节，同时要更新出站清单（SECURITY.md），第三方会收到被查的词。
  - 切换来源后旧缓存失效，录音会重新获取。
  - Google 端点可能随时被限制或失效，失败静默（不弹通知、不重试），与有道相同；它的稳定性与条款都没有保证，读者选它时自担。
  - Cambridge 需要解析词条页（实测约 200–350 KB，而不是 mp3 的几 KB），且要求浏览器式的客户端。在它的条款与拦截策略得到明确结论之前，不接入。
  - 实测（`SpeechSourcesProbe`，真实端点）：有道与 Google 的美式、英式各返回 mp3。
