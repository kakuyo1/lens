# 0112 气泡上的解释语言快捷切换让位于按住的母语一瞥

- **状态**：accepted（取代 ADR-0067）
- **背景**：ADR-0067 在气泡上放了 “地球 + 语言代码” 的快捷切换，读者点开一条五门语言的选择带，选中即写全局解释语言并重取卡片。它解决了 “换语言要跑设置页” 的问题，但也把 “读英文释义” 变成一个可随时被一次误触终止的状态：读者明明在练英文，一个常驻按钮却随时邀请他退回母语。解释语言应是读者在设置里定下的立场，不是每张卡片上的一个选项。
- **决定**：移除气泡上的语言快捷切换（选择带、`reexplainIn` / `reexplainChainIn` 与语言重取路径一并移除）。替代它的是**母语一瞥**：解释语言为英文时，卡片标题行关闭按钮左侧有一枚弱化的地球按钮，**按住 500 ms**（进度环走满一圈）后，卡片在释义下方用一行 12 px 弱文字浮出该词的母语释义，**松手即收**；读屏按压动作为同义的一次按下，行到卡关为止。目标语言取设置里新增的母语一项（mother tongue，目录语言表去掉 English，默认中文），它在阅读学习页位于解释语言上方。永久切换解释语言只留在设置里——“离开英文” 从一键变成一个持续的动作。
- **数据来源**：单词通道的答案本就恒定携带中英对，母语为中文时一瞥直接取当卡缓存条目的 `zh`，一次请求都不发；其余母语走新增的 `peek` 通道（`data/llm/request.peek.json`）：一个词进去、一行译文出来、不流式——按住的姿势画不出半个字，失败也安静（预算到顶、未配 key、请求失败都不出通知）。会话内按 “母语 + 词” 记住已付过费的行，同一词第二次按住不再花钱。译文气泡、词汇列表悬浮复习卡、链下层、预览卡与句子/实体卡都不出现地球。
- **后果**：习惯一键切换语言的读者要进设置才能永久换语言，这是有意付出的代价；作为交换，卡片少一个常驻控件，解释语言不再被误触改写。中文母语读者的一瞥是免费的（对已在缓存里的中英对），西语 / 日语母语读者的一瞥每次一词一小笔费用、每个词每会话至多一次。被取代的 ADR-0067 的 “重取保留卡片左上角与高度”（`languageReplay`）随快捷切换一起移除。
