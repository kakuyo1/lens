# 0052 牌子由手握着杆子举起，随身体起伏，大小随宠物

- **状态**：accepted（2026-10-17），与 `ui-prototypes/pet-review.html` 一致。小卡的窗口形式、宠物是否挪动、手的位置来源，见 ADR 0053。
- **背景**：早先的版本把牌子固定在宠物胸口六成高的位置，牌子的尺寸又被夹在最小倍率上。在 `ui-prototypes/pet-review.html` 上试过：小宠物（×1–×1.6）时牌子盖住整只宠物，杆尾低过脚；大宠物时牌子相对身体显小；牌子悬在身体旁边，看不出是被拿着的。
- **决定**：
  - 牌子由手握着。杆从牌子靠近身体的一侧伸下，杆尾埋在手的拳头里，牌子悬在手的上方、朝外展开。杆与牌由 UI 绘制；手是宠物 `ask` 动作的一部分。
  - 手在身体侧缘、胸口一行，与身体同锚点，逐帧随身体上下起伏，牌子跟着它起伏。右手在右，左手在左，两者镜像。
  - 左手为默认（用户定，取代原先的右手默认）。左侧的外侧与内侧小卡都放不下时才换右手，两侧都放不下取溢出少的一侧，不整块左移。
  - 牌子整块随宠物倍率等比缩放，取消 0.6 的下限夹值；小卡与按钮不缩放，点击区不随宠物变小。
  - 小卡朝牌子的外侧展开；外侧放不下才翻到内侧。
  - 作答气泡在举牌的手那一侧，与宠物垂直居中；那一侧放不下才翻到另一侧。
- **后果**：
  - 被排除的方案：杆在牌子正下方居中（UI 原设计）。手要伸到牌子下方，结果不是牌子压住身体，就是要画一条很长的胳膊。固定六成挂点加夹值（上一版）：小宠物被盖住，大宠物显小。小卡只向右：左手时小卡会盖在宠物上。
  - 按比例缩放的代价：×1 时字约 6 px，读不清。给字号设下限会重新挡住身体，是否加下限待定。
  - 没有 `ask` 动作的第三方宠物没有手可握，牌子的去处待定。
  - 手的像素图已装入 `data/pet`：右手在 `effects/ask.png`，左手在 `effects/ask-left.png`，动作的 `effectLeft` 指向左手图。应用已在装载时读取 `effectLeft` 并量出握点（见 ADR 0053），美术做法见 `docs/pet-art-pipeline.md` 第 8 节。
