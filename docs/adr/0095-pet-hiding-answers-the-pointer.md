# 0095 躲藏的宠物回应指针：靠近注视、单击引出、拖到边缘缩入

- **状态**：accepted（2026-10-24）。修订 ADR 0066 “其他状态归零” 的躲藏例外与 ADR 0076 的 “躲藏时暂停悬浮与注视” “单击不结束”。
- **背景**：躲藏（ADR 0076）落地后，露出的那一小条身体成了屏幕边缘一件安静的东西：指针凑近没有反应，单击既不结束躲藏也没有反馈，只有拖动能把它请出来；反过来，读者把宠物拖到屏幕边缘松手，它只是呆站在落点，要等下一次闲逛才可能自己躲进去。躲藏本该是 “藏起来偷看”，而不是 “消失”。
- **决定**：
  - **躲藏时注视恢复，反应仍不触发**。躲藏稳定后（滑出完成、未被拖动、无提问、偷看循环在播），悬浮轮询继续，距离量到**露出的那一小条**：偷看墨迹按工作区边缘裁剪后的可见部分，单位仍是画布像素，注视圈仍是各宠物的 `gazeRadius`。指针靠近，眼睛沿主轴跟转 ±1 画布像素，窗口在偷看循环之上**多探入 12 px**（180 ms 缓动进出）；指针离开即收回。`idle` 恒为 false：notice / dwell 反应与冷却完全不参与躲藏——宠物只看，不演。
  - **单击露出的部分把它引出来**。单击不再被躲藏吞掉：窗口从当前位置缓动滑回躲藏起点（躲藏开始时窗口所在处，按当前工作区夹紧），滑到即结束躲藏，该点成为 home 并写入设置。这一下不播 `click_react`、不累计愤怒：引出是邀请，不是戳。提问进行中单击与拖出同规则：躲藏结束，问题跟到新位置继续。
  - **拖到边缘松手，主动缩入**。一次放下（非抛掷）把窗口贴住或压出当前屏工作区的左右边缘（贴住 ±1 px 或任何压出），宠物确定性地躲进去，不掷闲逛那颗 70% 的骰子；抛掷落地保持 ADR 0090 / 0092 的行为，不因此躲藏。缺 `edge_peek` 的宠物照旧只是坐在松手点。
  - 全部落在控制器与 PetWander：无新增数据字段、无新增美术与角色，`hover` 块与 `movement` 块的缺席语义不变。
- **后果**：
  - 松手在边缘外的落点不再留下 “半只宠物卡在屏幕外” 的静态：这类落点一律收进躲藏。想让宠物停在边上，就让它躲着，或点一下把它引出来。
  - 躲藏期间窗口比过去多动两类：指针靠近的 12 px 探入与单击后的滑回。ADR 0076 的 `fitOnScreen` / `keepOnScreen` / `savePosition` 躲藏豁免不变；引出落点在边缘内侧、完整可见，可直接作为 home 保存。
  - ADR 0066 与 0076 被本 ADR 修订的仅限上列两句，其余继续有效。
