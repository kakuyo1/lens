# 0097 提问期间宠物看向牌与小卡

- **状态**：accepted（2026-10-24）。修订 ADR 0066 的 “其他状态归零” 与 ADR 0095 的躲藏注视：提问期间多一条方向。
- **背景**：木牌立在宠物脚边后，宠物在提问期间不是把眼神归零，就是（没有 `ask` 动作、仍在待机的包）继续跟着指针；读者看到的是宠物望向别处，而不是在问自己。牌和小卡的位置由 QML 按屏幕余量选，C++ 不知道它们在哪一侧。
- **决定**：
  - `ReviewSignWindow` 在牌可见期间把方向告诉 `Pet.setReviewLook("left" / "right")`：牌立着时是牌的一侧，小卡展开时是小卡的一侧，小卡收起后回到牌侧；问题结束、宠物关闭或牌子不可见时传空串清掉。只传方向，不传词。
  - 控制器把方向记成表情层沿 X 的 ±1 画布像素。方向非空期间，`updateHover` 的第一条规则就是用它，压过指针跟随、鼠标穿透、躲藏偷看和非空闲状态；它不触发 notice / dwell，也不改变躲藏的探入。
  - 记得、忘了、90 秒不理、关闭宠物与下一次提问前都会清空方向；清空时忘掉被牌打断的那一轮悬浮，眼睛回到当前状态下应有的位置。
- **后果**：
  - ADR 0066 的 “其他状态归零” 与 ADR 0095 的躲藏注视多出一个例外，范围只在牌或小卡可见的这段时间。
  - 没有 `ask` 动作的第三方包得到同样的侧眼；牌侧与卡侧沿用已有的 `choose()`，没有新增几何、数据或美术。
  - 只移动表情层 1 px；`ask` 姿势、配饰、身体和窗口都不动。
