# 0050 复习由宠物举牌提问，等级按遗忘曲线升降

- **状态**：accepted（2026-10-17）
- **背景**：查词历史已经在了（`StatsStore::history`，2000 条），但没有任何复习机制；词汇弹窗的悬浮只能 “看”，不能检验记忆。另做一张复习页会多一个常驻入口和一套与宠物无关的界面，而产品已经有一只一直在桌面上的宠物。
- **决定**：
  - **两个时钟**。每个词有自己的复习等级与到期时间（0–5 级，间隔 10 分钟 / 1 天 / 3 天 / 7 天 / 21 天 / 60 天）；宠物多久看一次有没有到期词由设置里的频率决定。频率不参与等级间隔的计算，调频率不会改变曲线。
  - **答对升一级，答错降一级**。0 级失败仍是 0 级；到期时间按新等级的间隔从作答时刻重算。第一次进入复习的词取 1 级，到期 = 最后一次查阅 + 1 天。
  - **问所有查过的词，含已会**。已会只表示 “不再自动弹”，复习正是要查它是不是真记得。复习等级**独立于**已会 / 新词标记，作答不改写标记、不改写词汇统计。
  - **只问缓存里有释义的词**。作答后的气泡复用当前解释语言下已经存下的解释，不发请求、不记一次查阅。没有缓存的词跳过，不为了复习再花钱。
  - **牌子是独立窗口**，不是宠物窗口的一部分。宠物窗口的尺寸被 `canvas * scale` 与场景、拖动、贴边逻辑绑死，往里塞一张会展开的牌会牵动这些。牌子跟随宠物、排除抓屏（否则自动扫描会读到牌上的词）、不收焦点。牌面只有单词，用随包的像素字体；悬浮才展开两枚按钮。
  - **左右由宠物与屏幕余量共同决定**（牌子的左右与小卡的侧别由 ADR 0052 决定，与 `ui-prototypes/pet-review.html` 一致）。作答气泡朝牌子所在的一侧展开，那一侧放不下才翻到另一侧，两侧都放不下留在牌子所在的一侧并夹进工作区。牌子的屏幕位置不因悬浮而移动。牌子与气泡出现时都 `raise()`，保证压在宠物窗口上面。
  - **宠物侧只加一个可选角色与四个事件**。`Role::Ask` 与 `PetEvent::ReviewAsked / ReviewRemembered / ReviewForgotten / ReviewIgnored`；`ask` 角色可缺省，第三方宠物包没有它时牌子照常出现，只是没有动作。单词文本**不经过** `PetEvent`，仍由 `ReviewDuty` 直接交给 QML，状态机只收枚举。
  - **不答就收**。90 秒后收牌、演生气，不弹气泡；词保持到期，但 2 小时内不再抽中它，避免每次检查都问同一个词。
  - **阶段一不同步复习等级**。跨设备合并要决定两边的等级与到期时间怎么并，不是 “取较新” 一句话能覆盖的；先留在本地。
- **后果**：
  - 四只随包宠物各需一个 `ask` 动作。它由美术流水线复用现有身体帧合成，不新画轮廓（手的例外见 ADR 0052）；配饰的 `supportedActions` 必须补上 `ask`，否则戴着配饰举牌时配饰会消失。
  - 牌子窗口与宠物窗口一样要 `WDA_EXCLUDEFROMCAPTURE`。这不是可选项：牌上的词被 OCR 读到会再触发一次解释。
  - 作答气泡走缓存显示路径，**不走** `showStored` 那条会记录查阅的路径；也不显示学习判定按钮——复习结果与人工标记是两条线。
  - `review` 键与 `history` 分开存。历史截断不删复习等级；`removeWord` 同时清掉两者。
  - 设置里的频率四档（关闭 / 15–30 分钟 / 30–60 分钟 / 1–2 小时）只控制检查节奏；初始默认 30–60 分钟。
  - 复习等级不进同步、不进统计、不出现在任何面板上；读者看到的只有宠物举牌。
