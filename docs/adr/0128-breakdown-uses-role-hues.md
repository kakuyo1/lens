# 0128 句子拆解用四个角色色标成分

- **背景**：句子拆解要给一句英文里的成分上色，让读者一眼认出主语、谓语、表语和状语。DESIGN.md 的 One Green Rule 只允许状态绿一个语义色，Don't 禁止引入第二个语义色相。候选稿里三种画法（色下划线加角色签、只用色下划线、色底）都要靠颜色区分成分，只用灰阶分不开四类成分。
- **决定**：引入四个角色色（主语蓝、谓语玫红、表语青、状语琥珀），定义为角色色而非语义色：只标成分，不表示状态，不进入按钮、选中态或表面底色。画法取色底：成分底色为该角色色 16%，文字保持正文色，气泡底部配图例写出角色名。令牌与数值见 DESIGN.md 3.1e。拆解画在 Lens 的解释气泡里，不叠在原应用的选区上：选区只给松手点（`docs/adr/0056`），拿不到词的位置；叠线要靠 UI Automation 或 OCR 取词框，两者在目标应用上都不稳。
- **后果**：状态色仍只有 `ok` 一组，One Green Rule 的其余条款不变。色底与气泡底的对比约 1.2–1.4:1，色底不作边界依据，边界靠文字与图例承担。红绿色盲下四色是否可区分尚未模拟验证，落地前要补。角色色不得移作状态用途；若需要第五个角色，须另开 ADR。
