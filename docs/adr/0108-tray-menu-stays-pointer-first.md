# 0108 托盘菜单保持指针优先

- **状态**：accepted（2026-10-25）。
- **背景**：曾试过让托盘菜单在打开时接管焦点，以便键盘读者进入设置、换语言、退出。实机看下来，首开时焦点环和首行高亮抢走了托盘卡片原本安静的第一眼；读者也不希望一个被动扫过的菜单改变前台窗口。这个取舍由产品方在 2026-10-25 裁定回退。
- **决定**：
  - 托盘菜单不接管焦点：使用 `WindowDoesNotAcceptFocus`，不设 Tab 站与焦点环。
  - 语言行与语言项保留 `Accessible` 角色、名称与按压动作；指针 hover / 点击展开与选择，`Esc` 收菜单。
  - 菜单窗口不再 `requestActivate()`，也不把焦点放到首行。
- **后果**：
  - 键盘专用读者不能用 Tab 操作托盘菜单；这是换取首次观感与不改变前台窗口的代价。
  - 这条与 ADR 0107 的无焦点浮层地板同向；菜单的外观不因焦点而改变。以后若要恢复键盘路径，需要先重新裁定，而不是悄悄加回 `requestActivate()`。
