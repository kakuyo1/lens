# 0208 PotPlayer 字幕扫描走字幕文件加播放时钟

- **状态**：accepted（2026-11-21；收编 POTPLAYER-PLAN.md，该文档随之删除）
- **背景**：视频字幕扫描长期标 “待上线”。OCR 不适合：视频文字逐帧变化。PotPlayer 本身暴露得足够多：播放位置、状态与视频尺寸可经窗口消息取回（`WM_USER` 20484 / 20486 / 24624 / 24625），媒体路径可从进程命令行或播放列表文件取得；字幕文本在外挂 SRT/ASS/SSA/VTT 或内嵌文本轨里，比像素多出精确文本、cue 时间与上下行。Translate 扩展探针因需实时翻译、改动渲染被否，仅记档作流/未知轨的备选。
- **决定**：
  - 路线（D1）：字幕文件 + 播放时钟，零新依赖——原生 SRT/ASS/SSA/VTT 解析器加最小 Matroska 文本轨提取（EBML 走查、payload 跳读、压缩轨跳过并记日志）。
  - 来源优先级（D2）：视频旁的外挂字幕（`stem.LANG.ext` / `stem.ext`）胜出，否则内嵌文本轨；位图轨（PGS/VobSub）与 ContentEncoded 跳过。
  - 轨道选择（D3）：forced 排除；CJK 为主的样本排除；英语语言标记与默认标记加分，SDH/CC 名减分，轨道号小者优先；外挂候选 en/eng 后缀 > 无后缀 > 其它。
  - 媒体路径（D4）：窗口标题文件名须与解析出的路径文件名一致（命令行与播放列表两路），不匹配则跳过该窗口并记一次日志。
  - 几何（D5）：视频矩形按窗口内最大可见子窗口适配居中（工具栏与控制条画在客户区内，客户区矩形会低约 65 px）；字幕字体取 CaptionStyle 注册表，缺省 Segoe UI 15 / 700；cue 保留源换行，`\an` 顶部 cue 画在顶部边距，`\pos`/`\move`/中锚跳过。
  - 集成（D6）：`ScanForeground::Kind::PotPlayer`；`SubtitleTrack`（`src/app/platform/`）独立 worker，轮询时钟（播放 50 ms / 暂停 150 ms），cue 或字幕带变化才出帧，解析缓存按 path+mtime 两槽。播放器置顶（OnTopMode=2）会盖住标记与宠物：铅笔层与宠物在显示期间按 1 s 节奏重提。
  - 设置（D7）：`autoScanPotplayer`（缺省开）替换 “视频字幕——待上线” 行，标签 PotPlayer，五语种翻译。
  - 已知边界（D8），记日志不隐藏：播放器自身的字幕延迟/位移覆盖会让真实字幕带偏移（按默认位置画）；播放器关字幕无法感知；PotPlayer 选轨与本地选择不一致时行会错位；网络流不在范围。
- **后果**：换播放器（VLC 等）要走各自的消息面，另立决定；窗口缩放与全屏下的字幕带度量仍待真人验收（见 PRODUCT.md 留待后续迭代）。
