# 0126 复习牌的动效只在牌内发生，脚线不动

- **状态**：accepted（2026-10-26）。
- **背景**：七块选定的牌子各需要一个小动效。第一版纸箱蝴蝶结的动效是蝴蝶结的两个环一开一合，读者认为它容易引出不好的联想，被否决，改为胶带上的白点缓缓滑动。
- **决定**：
  - 动效只发生在牌子内部。牌子的位置、宠物、脚线都不动。每块牌的所有帧脚线相同（原型里已逐帧核对，最大差 0.01 px）。
  - 每块牌一个动效，选定的是：纸箱蝴蝶结胶带上的白点缓缓滑动；骨头牌一道白光从左到右扫过；小蜡烛火苗摇曳，两颗星星轮流闪；小鱼缸小鱼来回游，泡泡上升，水面起伏；小云朵星星一大一小地闪，圆点流动；纸杯蛋糕糖粒跳动，樱桃闪光；书袋卡星星贴纸闪烁，书袋里的心跳。
  - 动效是预先画好的逐帧画面，由一个共用时钟切换。帧数与帧间隔属于美术数据，界面里不写毫秒数（与 `DESIGN.md` 的动效规则一致）。原型里的 120 ms 只是占位。
  - 动效跟随应用的 “动画效果” 设置：关闭时停在第 0 帧，与其他表面的减少动效一致（`DESIGN.md` § 减少动效）。原型用的 `prefers-reduced-motion` 只是占位。
  - 不做拟人化或开合类的动作。以后给候选加动效，同样按这条标准过。
- **后果**：
  - `DESIGN.md` 的动效原则写的是 “动效只用于反馈与状态变化，克制”。牌子的循环动效属于宠物随身的装饰，与 ADR 0101 把宠物表演放进数据是同一思路。这一点要由 `DESIGN.md` 明确，未决。
  - 动效要求逐帧画面，美术数据随之变大（最多 6 帧）。未核对体积。
  - 被排除的方案：蝴蝶结开合（被否决）；整块牌子上下浮动（脚线会离地，违反 ADR 0088 的站位）。
