# 0132 RapidOCR 的模型目录只接受 ASCII 路径

- **状态**：accepted。实现于 2026-10-28；Windows 适配器仍不启用。
- **背景**：RapidOCR-json v0.2.0 的模型目录含非 ASCII 字符时，子进程在初始化前以 `0xC0000409` 退出，stderr 为空；可执行文件与工作目录含中文则能运行。读者安装位置无法预先保证纯 ASCII，因此不能把失败留给子进程。
- **决定**：模型目录必须是本机绝对、存在的 ASCII 路径；设置页在路径可显示后立即警示，检测按钮禁用，捕获门报告 `path-unsupported`，不静默回退 Tesseract。程序路径可以含非 ASCII。首次使用必须显式检测并信任，信任摘要绑定可执行文件、模型目录和 Lens 语言选项会用到的全部模型文件；切换识别语言不重新要求信任，改变任一文件都撤销信任。Lens 不复制、不联接、不改写读者的模型目录。
- **后果**：用户名为中文或安装目录含中文时，读者必须把模型目录移到 ASCII 路径才能使用 RapidOCR；这是本轮接受的限制，替代方案（Lens 自有 ASCII 缓存或 junction）被排除。安装包仍不带 RapidOCR 或其模型；第三方程序以当前用户权限运行，设置页必须说明其可读其他文件或联网。ASCII 限制不改变自动策略：Auto 仍只考虑 Windows 与 Tesseract，RapidOCR 只能明确选择。
