# 0124 句子卡与实体卡也有母语一瞥的地球

- **状态**：accepted（2026-10-26）；部分取代 ADR-0112，其中 “句子卡与实体卡不出现地球” 一条作废
- **背景**：ADR-0112 把母语一瞥限在词卡，理由是词卡的中英对由词通道随解释一起买下，可以免费复用；句子与实体的答案不进缓存，中文对拿不到，也没有词作为键。读者仍然希望在句子与实体卡上按住地球，看这段文字的母语释义。
- **决定**：
  - 词卡、句子卡与实体卡在解释语言为英文时都有地球，位置、500 ms 按住、一行释义、松手即收与词卡相同。译文气泡、词汇列表悬浮复习卡、下钻层与预览仍不出地球。
  - 请求与答案的键是 `CardSession::peekKey()`：词卡为 lemma，句子与实体为所选文字，因为它们没有 lemma。
  - 中文母语：词卡仍取当卡缓存的中英对；句子与实体的中文也走 `peek` 通道。
  - `data/llm/request.peek.json` 的输入改为 “一个英文词、短语或句子”。
- **后果**：
  - 句子与实体上的每个文字每会话多一次母语请求，中文母语也一样，计入同一日预算；预算到顶时按住无声。
  - 实体卡的标题在没有音标与词性时让出头部控件的宽度（`BubbleTitleRow.headerReserve`），长专名不再压在地球与关闭之下。有音标或词性的一行保持原宽度。
- **被排除的方案**：句子与实体也进缓存，以免费拿中文对——要改缓存键、失效规则与存储范围，超出一个手势的改动。为句子与实体另开一条 peek 通道——同一条提示词多写一句即可，多一条通道多一份协议。
