4. 事件与动作角色

事件（PetEvent）动作角色优先级
DragStart 拖动开始pickup拖动
DragEnd 拖动结束idle空闲，打断一切
Click 单击click_react单击（拖动中忽略）
SelectionShown 选区动作条出现look_around事件
ExplanationRequested 解释请求thinking事件
ExplanationShown 气泡出现study（保持）事件
ExplanationHidden 气泡消失结束 study，回到空闲—
KnownMarked、UpdateAvailablecelebrate事件
NewWordMarked 标记新词encourage事件
BudgetPaused 预算暂停sleep（保持）事件
BudgetResumed 预算恢复结束 sleep，回到空闲—
内部：约 3 分钟无事件yawn，结束后进入 sleep情境
内部：空闲约 20–40 秒idlePool 中随机一个情境

优先级从高到低：拖动、单击、事件、情境、空闲。思考等待解释超过 30 秒即回到空闲。

10. 规格与代码的偏差

文档写的是现状
PHASE3 §3.8扁平的 data/pet/*.json每只宠物一个子目录 data/pet/ID/（ADR 0031）
PHASE3 §3.8pet.json 含默认配饰代码不读取该字段
PHASE3 §3.1、§3.4tools/build-assets.py；data/pet/accessories.json脚本在 scripts/pet/；配饰表在各宠物目录
ADR 0030新增动作名不需要改代码设置页的动作名与配饰名是 QML 中的 switch，新名字只显示原始 id
pet.json含 height代码不读取（无害，但不一致）
JS 原型与 C++ 同一套规则状态机在 pet-engine.js 中重复实现，无跨实现的共享用例
